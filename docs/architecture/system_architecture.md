# DevLink 系统架构（第一阶段）

## 总体结构

Qt 桌面端和 Vue Web 端是平等客户端。设备数据由 C++/Qt 后端统一管理，客户端不维护权威设备状态，也不应绕过后端直接操作硬件。

    Qt Widgets Desktop ── REST / WebSocket ──┐
                                             ├── C++ / Qt Backend ── DeviceStore
    Vue 3 Web Client ───── REST / WebSocket ──┘

## 通信职责

- REST API（8080）：设备新增、查询、修改、删除。
- WebSocket（8081）：推送设备变化事件和初始快照。
- DeviceStore：第一版内存存储，作为当前运行期间的唯一设备状态来源。
- 客户端收到 WebSocket 事件后重新获取 REST 快照，降低增量事件丢失造成的数据不一致风险。

## 第一阶段边界

当前原型不包含数据库持久化、登录鉴权、角色权限、审计日志、物理设备驱动和断线事件回放。后端重启后内存设备数据会丢失。只应在可信任的开发局域网运行，不应直接暴露到公网。
